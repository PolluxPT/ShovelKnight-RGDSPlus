# Changelog

## v0.1.0-beta.1 — 2026-11-08

First public beta based on the owner-confirmed working Alpha 1.4 x86_64 route. Retains the tested Box64 core, native SDL/GL4ES bridge, final PCM volume curve, calibrated physical controls, exit combination and device-state restoration.

Adds a clean public installation package and automatic import from a user-owned GOG Linux 4.1 installer or extracted game folder. Removes private game content from distribution. Includes source, licenses, source-download references and publication instructions.

Extended all-campaign testing remains outstanding.
