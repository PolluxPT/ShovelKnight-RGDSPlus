# Shovel Knight RGDS+ — Beta 1

Standalone Shovel Knight: Treasure Trove for the Anbernic RGDS+ stock Linux environment. No PortMaster required. The owner confirmed the working x86_64 game route on hardware.

Download **ShovelKnight_RGDSPlus_Beta1_Install.zip** below. Copy APPS into Roms on your memory card. Put your own **shovel_knight_treasure_trove_4_1_36252.sh** GOG Linux installer in **Roms/APPS/ShovelKnight_RGDSPlus/gamedata/**, then launch ShovelKnight.sh. The first launch imports your files automatically and may take several minutes.

If updating the working Alpha 1.4, merge and replace the APPS files while retaining game/ and savedata/.

Includes D-pad/left-stick movement, calibrated physical buttons, working volume keys, startup-safe volume curve, restoration of the original system volume, lower-screen shutdown/restoration and START+SELECT hold to exit.

**Own game required.** No commercial game files, FMOD or game assets are included. Only the GOG Linux Treasure Trove 4.1 release is currently supported.

This is a **pre-release**. Extended testing across every campaign/mode has not been completed. The runtime may print a teardown diagnostic after normal shutdown; the supplied working session returned exit code 0 and restored device state. See README for beta observations and support instructions.
